## Overview

**ESA Industry Space Days** is an ESA event that brings European space companies together with the Agency. This project covered the web copy for the event website.

## The challenge

An event website has to answer practical questions quickly: what the event is, who it is for and how to take part. The copy needed to be clear for an international industry audience.
