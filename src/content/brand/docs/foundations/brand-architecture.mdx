```text
One personal identity
→ Multiple focused public sites
→ Shared voice, tokens, components and asset standards
→ Site-specific purpose and visual variation
```

<Callout title="Different personality is not a different brand identity">
Every site keeps the same name treatment, core type system, base spacing scale, accessibility rules, link behaviour, metadata pattern, image-caption conventions, writing principles, logo usage and footer attribution.
</Callout>

## What may vary per site

- The accent colour, applied to highlights and borders only.
- Voice emphasis, within the shared writing principles.
- Layout density and imagery, within the shared spacing scale.

See [site profiles](/brand/sites/overview/) for each site's purpose, audience and accent.
