## Rules

- A button starts an action. A link goes somewhere. Do not style one as the other.
- Name the result: "Book time", not "Submit".
- Links inside text are underlined and use the shared link colour on every site.
- Focus is always visible. Do not remove outlines.
- Buttons use the `--button-*` tokens. Site accents do not change button colour.
