## Rules

- Text and link pairs must reach 4.5:1 contrast in both themes. `npm run validate` checks this.
- Site accents are decorative. Never use them as the only carrier of meaning or as text colour.
- Every page works in light and dark. Follow the system setting unless the person chooses otherwise.
