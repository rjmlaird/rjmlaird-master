---
An asset is approved when all of these are done:

1. Creator, copyright owner and licence are recorded.
2. Approved and prohibited contexts are listed.
3. Alt text is written. Caption guidance is added where needed.
4. An optimised copy is on the CDN and the master is recorded in the DAM.
5. A review date is set.

`npm run validate` checks the manifest structure. `npm run check:cdn` confirms the files respond.
